# Image assets

Drop your image files into this folder using the **exact names** below (any
extension: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`, `.svg`). They are picked
up automatically — no code changes needed. Until a file exists, that spot
shows a dashed placeholder box on the site.
