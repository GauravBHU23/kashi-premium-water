# AI Image Prompts — Kashi Premium Drinking Water

Copy any prompt below into an AI image generator (ChatGPT/DALL·E, Bing Image
Creator, Midjourney, Adobe Firefly, etc.), download the result, and save it
into this folder (`src/assets/images/`) using the **exact file name** given.
The site picks it up automatically — no code changes needed.

A consistent style line is added to every prompt to keep the bottle label
and color palette uniform across all photos: navy blue (#0a2647) and sky
blue (#2e7bc4) brand colors, droplet logo, "KASHI PREMIUM DRINKING WATER"
text on the label.

## Tips for best results
- Add **"transparent background"** or **"isolated on white background, easy
  to cut out"** to any bottle/product prompt if your generator supports it —
  this makes the bottle shots drop cleanly onto the site's white/light-blue
  sections.
- Keep the label wording consistent ("KASHI PREMIUM DRINKING WATER" + blue
  droplet logo) across all bottle prompts so every product shot looks like
  the same brand.
- If a generator can't keep label text legible/consistent across multiple
  generations, generate one good bottle shot, then re-use/composite it
  (e.g. with Photopea/Photoshop) for the other sizes instead of
  regenerating each one from scratch.
